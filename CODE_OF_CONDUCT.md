# Code of conduct

Participation in AnimeRoyale's issues, pull requests, and discussions should be respectful, constructive, and safe.

## Expectations

Discuss ideas and implementation choices without attacking people. Give specific, actionable feedback, accept corrections, and make room for contributors with different backgrounds and experience levels.

Harassment, threats, discriminatory abuse, repeated unwanted contact, and disclosure of another person's private information are not acceptable. Playful application commentary is not permission to target contributors or other users.

## Raising a concern

For a non-sensitive concern, ask a repository maintainer for help in the relevant discussion. For a report involving private information, request a private contact without publishing details. This repository does not establish a dedicated conduct-reporting email address.

Security vulnerabilities should follow the [security policy](SECURITY.md).

## Moderation

Maintainers may remove inappropriate content, close discussions, or restrict participation to protect contributors and the project. Responses should be proportionate to the behaviour and its impact. This document does not promise a response deadline or confidential reporting infrastructure.
